## 常用命令速查

```bash
git status              # 看改了什么
git add -A              # 全部加入暂存区
git commit -m "说明"     # 存档
git push                # 上传到 GitHub
git pull                # 拉取远端更新
git log --oneline -5    # 看最近 5 条提交
```
